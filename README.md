# Code with Mahmoud — منصة الطالب والأدمن

واجهة عربية أولية لمنصة بسيطة مكوّنة من تسجيل/دخول، صفحة للطالب، وصفحة للأدمن. مبنية بـ HTML وCSS وJavaScript وتستخدم Firebase Authentication وFirestore وStorage.

## إعداد Firebase قبل الاستخدام

1. أنشئ مشروعًا في Firebase Console وأضف تطبيق Web.
2. انسخ بيانات التطبيق إلى `firebase-config.js`، وحدّث رقم واتساب بصيغة دولية من غير `+`.
3. فعّل Email/Password في Authentication.
4. أنشئ Firestore Database وFirebase Storage.
5. انشر `firestore.rules` و`storage.rules` على مشروع Firebase.
6. أنشئ حساب الأستاذ من صفحة التسجيل، ثم من Firebase Console غيّر `users/{uid}.role` إلى `admin`. إنشاء الحساب وحده لا يمنح صلاحية الأدمن.
7. افتح `index.html` عبر خادم محلي أو Firebase Hosting. وحده فتح الملف مباشرة قد يمنع تحميل وحدات JavaScript.

## الموجود حاليًا

- إنشاء حساب طالب بالاسم والبريد والهاتف والمرحلة وكلمة المرور.
- دخول الطالب والأدمن بحسب الدور المخزن في Firestore.
- رفع فيديوهات الدروس من لوحة الأدمن.
- نشر واجب، واستلام إجابة نصية أو مرفق صورة/PDF.
- نشر امتحان اختيار من متعدد واستلام إجابات الطلاب في لوحة الأدمن للمراجعة.
- تحديث حالة اشتراك الطالب وإظهار رابط واتساب.

الامتحان في هذه النسخة يجمع الإجابات للأستاذ ولا يحسب الدرجة تلقائيًا. إعداد Firebase وإضافة رقم الواتساب وحساب الأدمن خطوات لازمة قبل أن تصبح الخدمات الحقيقية متصلة.

## النشر على GitHub Pages

1. ارفع محتويات مجلد `platform` إلى جذر المستودع، أو عدّل مسارات الملفات إذا وضعتها داخل مجلد فرعي.
2. من إعدادات المستودع افتح **Pages**، واختر النشر من الفرع الرئيسي ومجلد الجذر، ثم احفظ.
3. أضف نطاق موقع GitHub Pages إلى **Authentication → Settings → Authorized domains** في Firebase، مثل `username.github.io`.
4. ضع بيانات Firebase الحقيقية ورقم واتساب في `firebase-config.js` قبل النشر.
5. استخدم رابط الموقع المنشور. لا تفتح ملفات HTML من الجهاز مباشرة عند اختبار خدمات Firebase.

GitHub Pages يستضيف الواجهة الثابتة فقط؛ Firebase مطلوب لتسجيل الحسابات وتخزين البيانات والفيديوهات والواجبات.
